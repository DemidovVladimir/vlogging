# Шрифты TENGU

В папке находятся устанавливаемые TTF, веб-файлы WOFF2 и лицензии OFL.

| Семейство | Назначение | Файлы |
|---|---|---|
| Manrope | Русские заголовки и обложки | Variable TTF |
| IBM Plex Mono | Метаданные, категории, координаты | Regular, SemiBold, Bold TTF |
| Literata | Цитаты и редакционные карточки | Variable Roman и Italic TTF |
| Shippori Mincho | Японская печать и редкие акценты | Regular и Bold TTF |

`TENGU` не является шрифтом. Фирменное слово хранится в `source/svg/tengu-wordmark-custom.svg` как оригинальные кривые.

Шрифты получены из официального репозитория Google Fonts. Каждое семейство распространяется по SIL Open Font License; текст лицензии расположен в соответствующей подпапке.

Для веб-проектов используйте `fonts/web/`. Для локальной установки и графических редакторов используйте TTF.
