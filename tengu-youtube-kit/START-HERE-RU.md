Можно короче: вызвать навык и назвать тему. По умолчанию полный новый выпуск готовится на русском и английском, примерно по пять минут, для взрослого зрителя без обязательной технической подготовки, затем публикуется после проверки. «Только русский», «черновик» или «пока не публикуй» переопределяют этот порядок. Сценарии и планы всегда остаются отдельно и непубличными.

Это не обещание, что любая новая тема получится без единой правки. Навык фиксирует уже принятые решения и добавляет проверку качества, чтобы не обсуждать их заново.

## Что сохраняется

- TENGU: тушь, тёплая бумага, красный акцент, техническая типографика.
- Те же кайдзю, робот, точная векторная надпись и знак.
- Локальные шрифты и их лицензии; исходные иллюстрации, заставки MP4, аудио и исходник английской заставки.
- Анимации со смысловыми фазами, паузой, откатом и регулировкой скорости.
- Сценарий и режиссёрский план отдельно от зрительского экрана.
- Живой связный рассказ: пример → причина → видимый результат → практический вывод.
- Проверки фактов, дубликатов, читаемости, времени, поведения анимации и сохранности брендовых файлов.
- Публикация обеих версий одним релизом Cloudflare Pages, без удаления старых выпусков и без загрузки приватных файлов.

Тема, примеры и число слайдов меняются. Старый сюжет про контекст не будет обязательной структурой каждого видео. Неизменный бренд не означает неизменный рецепт для любой темы или модели.

## Перенести на другой компьютер

Распакуй tengu-youtube-skill.zip. Внутри — этот гайд, установщик и полная папка навыка.

Нужен Node.js. Из распакованной папки:
- node install.mjs --target codex
- node install.mjs --target claude-code

Установщик копирует весь пакет в стандартную личную папку. Он не перезаписывает отличающийся существующий навык. Повторная установка идентичной копии безопасна. Не копируй один SKILL.md: без assets/source не будет файлов, которые сохраняют стиль.

Либо вручную перенеси папку artifact-template-tengu-youtube целиком в соответствующую skills-папку. Существующую другую версию сначала сохрани отдельно.

## Самостоятельно создать рабочую папку

node artifact-template-tengu-youtube/scripts/new-episode.mjs --out /absolute/path/episode-02 --topic "Новая тема" --language ru

Этот запуск копирует рабочую основу и отмечает её как черновик. Он сам не пишет новый сюжет. Затем агент по навыку заменяет содержание, сценарий и источники.

Проверка:
- Во время работы: node artifact-template-tengu-youtube/scripts/check-episode.mjs /absolute/path/episode-02 --allow-draft
- Перед сдачей: та же команда без --allow-draft.

Для второй языковой версии запусти создание ещё раз с отдельной новой папкой и `--language en`. Английский текст адаптируется под живую речь; это не механическая замена подписей.

Проверка файлов не заменяет просмотр всех слайдов и фаз анимации. Готовность не ставится автоматически.

## Управление при записи

- Вниз / Page Down / Space — следующий слайд.
- Вверх / Page Up / Shift + Space — предыдущий.
- Влево / вправо — шаг анимации назад / вперёд с паузой.
- P — пауза / продолжение; R — первая фаза на паузе.
- Минус / плюс — скорость; 0 — обычная скорость.
- Home / End — начало / финал.
- Заставка запускается кликом со звуком. Управление фазами относится к схемам, не к MP4.

## Публикация на tengucluster.com

Используется существующий проект Cloudflare Pages `tengu-presentations`. DNS уже подключён; для следующего выпуска повторно настраивать домен не нужно.

Первый выпуск остаётся в корне. Следующие получают стабильные адреса:

- RU: `https://tengucluster.com/episodes/<slug>/`
- EN: `https://tengucluster.com/en/episodes/<slug>/`

Новый деплой содержит весь предыдущий публичный сайт плюс новый выпуск. Для загрузки собирается отдельная папка `public/` с явным списком разрешённых файлов. Рабочий `dist/`, сценарии, режиссёрские планы, скилл, архив и служебные файлы не загружаются — даже в preview.

Порядок и нужные идентификаторы: `artifact-template-tengu-youtube/references/publishing.md`. Проверка пакета перед загрузкой: `scripts/audit-public.mjs`. После деплоя агент проверяет обе ссылки, видео, управление, мобильную вёрстку и 404 на приватных путях.

Доступ к Cloudflare проверяется в используемом агенте. Установка скилла не переносит токены Codex в Claude и не даёт новых прав. При отсутствии доступа агент сохраняет готовый пакет и сообщает конкретный блокер, не выдумывая успешную публикацию.

## Что внутри

artifact-template-tengu-youtube/SKILL.md — основная инструкция.
references/ — редактура, стиль, производство, совместимость и контрольные изображения.
scripts/ — создание новой папки, структурная проверка и проверка публичного релиза.
assets/source/ — полный статический рабочий образец на двух языках, медиа, шрифты, сценарии и технические исходники.
artifact-template.json и agents/openai.yaml — метаданные шаблона Codex.

Референс — только для чтения. Новый выпуск создаётся отдельно и публикуется по своему адресу в существующем Cloudflare Pages проекте. Исторические Sites-ссылки в эталонных исходниках не являются новым местом публикации. Для деплоя на tengucluster.com плагин Sites не требуется. Весь этот пакет и ZIP остаются приватными.
