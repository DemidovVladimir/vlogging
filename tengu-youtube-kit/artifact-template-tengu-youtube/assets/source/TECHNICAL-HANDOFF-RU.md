## Основные изменения v32

Слайд 10 показывает дизайн страницы мастерской керамики. Все варианты — авторские учебные макеты, не результаты вызовов LLM. Задача, текст и изображение неизменны. Меняются модель, подключение навыка и оформление результата.

Сцена .scene--skill-example использует migrationFrames и renderMigrationExample(), пять фаз по 5 секунд. Поля era/mode задают подписи, rule выбирает off/old/updated, design выбирает bare/structured/editorial/overloaded. Фазы: старая без навыка → старая с навыком → новая без навыка → новая с прежним → новая с обновлённым. Поле design применяется к сцене и .design-page. Один HTML-макет меняет CSS, содержание не заменяется. Названия migration сохранены, чтобы не затрагивать общий таймер.

Только текущее правило получает .is-shown и aria-hidden=false. В состоянии off прежний рецепт остаётся приглушённым с явной подписью «Навык отключён». Две цитаты занимают одну сеточную область, сохраняющую высоту. Макет имеет фиксированную высоту внутри каждого breakpoint. Изменения CSS завершаются за 650 мс, reduced motion выключает переходы.

Сравнение фазы 3 и 4 меняет только подключение прежнего навыка при новой модели. Переход от старой с навыком к новой без него не является контролируемым сравнением только моделей. Не объявлять демонстрацию доказательством качества конкретной модели.

dist/assets/ceramics-study-v32.png — сгенерированная предметная фотография, 1536×1024, непрозрачная. Весь интерфейс страницы и текст — редактируемый HTML/CSS. Использован один и тот же файл во всех вариантах. Промпт и происхождение сохранены в SOURCES.md. KATA — вымышленная мастерская для примера.

Технический пример с SQLAlchemy и его специализированный тест удалены из текущей редакции; доступны в истории Git v31. Общий tests/journey-smoke.cjs проверяет новые фазы, неизменность контента, изображения и геометрии. Сценарий и план синхронизированы с dist. Другие слайды не менялись.

## Анимации и навигация

Один общий таймер и animationTime() учитывают sceneElapsed, sceneStartedAt и animationRate. При скрытии вкладки время замораживается. Новый слайд начинает с первой фазы, сохраняя паузу и скорость.

- 02: три состояния .context-assembly через data-stage, по 4 секунды.
- 04: шесть contextFrames через renderContextComparison(), по 4,5 секунды. .is-connected и .has-answer раскрывают две колонки. Размер не меняется между фазами.
- 10: пять migrationFrames через renderMigrationExample(), по 5 секунд. Ручные фазы и reduced motion поддержаны.
- 03, 05–09: storySelectors выбирает смысловые блоки. .is-cue и data-story-step меняются через 3,6 секунды.
- 01 и финал: статичные композиции.
- Reduced motion: схема доступна без автоматического таймера, ручные шаги сохранены.

Вверх/вниз, Page Up/Down и Space меняют слайды. Влево/вправо меняют фазу и ставят паузу; P продолжает; R начинает сначала на паузе. Минус/плюс меняют скорость, 0 возвращает 1×. Физические коды клавиш, без перехвата Ctrl/Meta/Alt, форм, ссылок и кнопок. Ручные фазы не зацикливаются за первой и последней. Панели управления поверх кадра нет.

Переход 200 мс через View Transitions, при reduced motion мгновенный. finishTravel() безопасно завершает прерванный переход. Колесо/touch не перехватываются. Прямые ссылки выравниваются после загрузки шрифтов.
