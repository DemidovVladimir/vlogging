# Навигация сайта TENGU

Задача от 23.10.2026: сделать существующие выпуски видимыми и дать переходы между ними. Это оболочка сайта, не новая редакция презентаций.

## Публичные адреса

- Главная / каталог: `/` и `/en/`.
- EP.01: `/episodes/agent-context/` и `/en/episodes/agent-context/`.
- EP.02: `/episodes/tengu-cluster/` и `/en/episodes/tengu-cluster/`.
- EP.03: `/episodes/emudhra-ca-compromise/` и `/en/episodes/emudhra-ca-compromise/`.

Старые `/#slide-N`, `/#intro`, `/en/#slide-N`, `/en/#intro` перенаправляются в EP.01 с сохранением query и hash. Обычный `/` теперь открывает каталог. `/ru` и `/ru/` сохраняют прежний редирект.

## Работа с меню

- «Выпуски / Episodes» открывает список тем и ссылку на главную.
- RU/EN переключает язык текущего выпуска с сохранением номера слайда.
- H скрывает / возвращает новую навигацию сайта. Это не меняет исходную панель TENGU и анимации.
- В меню есть кнопка режима записи; `?record=1` сохраняет этот режим при перезагрузке и подходит для ссылки на запись.
- P, R, стрелки, скорость, скролл и интро работают как прежде.
- Диалог использует нативный focus trap и Escape. Его клавиатурные события не управляют слайдами под ним.

## Исходники и воспроизводимость

- `episodes.mjs`: только публичные названия, описания и маршруты.
- `build.mjs`: полный снимок из проверенного baseline + явный allowlist новых файлов.
- `catalog.css`: главная, адаптивная вёрстка; `site.css` / `site.js`: оболочка шести viewer-страниц.
- `previous/`: полный проверенный снимок до навигации, ID `e56daf0f-c3bf-42b6-89c5-51f21e5d0de8`.
- `public/`: 144 файла (142 статических + 2 hosting control files). Только эта проекция предназначена для публикации.
- Новые ресурсы подключаются с SHA-256-derived query version. Старые JS, CSS, media и шрифты сохранены побайтно.
- `verify.cjs`: RU/EN, 4 размера, 6 viewers, все переходы, кнопки, клавиатура, режим записи, звук и старые ссылки. Сравнивает весь main с предыдущими слайдами, нормализуя только пути ресурсов.
- `verify-public.mjs`: SHA-256 опубликованных 142 ресурсов + 120 закрытых путей, 404 и старые редиректы.
- `qa/`, manifests и deployment record — приватные отчёты, не часть публичного сайта.

`node build.mjs` отказывается брать изменившийся production baseline: после публикации это исторический сборщик конкретного релиза, не универсальная команда будущих публикаций. Локальный просмотр: `node serve.mjs`, только `http://127.0.0.1:4176/`.

Для browser QA нужен Playwright из bundled Node dependencies; путь к Chrome указан в verify.cjs. Публичный аудит: skill `scripts/audit-public.mjs`, предыдущий manifest из previous/, разрешены изменения ровно шести прежних HTML (два корня и четыре EP.02/03). Два EP.01 HTML и три site-ресурса — новые.
