# TENGU / EP.02 — Tengu Cluster

Новый выпуск по скиллу `artifact-template-tengu-youtube`. Один сквозной пример: сравнение сервисов рассылок для студии, без покупки. Не live-demo и не замер результатов модели.

## Смотреть

- RU: https://tengucluster.com/episodes/tengu-cluster/
- EN: https://tengucluster.com/en/episodes/tengu-cluster/
- Предыдущий выпуск сохранён на https://tengucluster.com/ и https://tengucluster.com/en/ .

9 экранов с интро и финалом; 25 фаз анимации. RU: 645 произносимых слов, EN: 622. Оценка обеих версий — около 5:01 с 25 секундами на интро и визуальные паузы. Чтение ведущего ещё не замерялось.

## Непубличные материалы

- `ru/SCRIPT-RU.md`, `en/SCRIPT-EN.md` — сценарии.
- `ru/STORY-PLAN-RU.md`, `en/STORY-PLAN-EN.md` — фазы, подсказки и тайминг.
- `ru/SOURCES.md`, `en/SOURCES.md` — проверенные исходники и оговорки.
- `content.mjs` — авторский текст обеих версий; `author.mjs`, `episode.css`, `render.js` — сборка нового выпуска поверх сохранённого шаблона.
- `QA.md`, `qa/` — проверки и кадры; `release/` — приватная операционная сборка, manifest и receipt.

Для репетиции: `node serve.mjs` из этой папки. Сервер слушает только 127.0.0.1:4174.

- Презентация: `/ru/dist/` или `/en/dist/`.
- Сценарий: `/ru/dist/script.html` или `/en/dist/script.html`.
- Режиссёрский план: тот же `script.html?view=plan`.

## Управление при записи

P — пауза; R — начало текущей анимации на паузе; ← / → — предыдущая/следующая фаза; − / + — скорость 0.25×–2×; 0 — обычная скорость. Down / PageDown / Space — следующий экран; Up / PageUp / Shift+Space — предыдущий. Home / End — интро/финал. Колесо и touch работают естественно. MP4 запускается кликом со звуком; управление фазами не перематывает видео. После последней фазы диаграмма остаётся на месте.

## Публикация и продолжение

Публичный снимок: **только `release/public/`**, 87 файлов, включая 35 неизменённых файлов EP.01. Рабочие `ru/dist/` и `en/dist/` публиковать нельзя: там есть сценарии и приватные читатели. Сам скилл тоже не публикуется.

Релиз: `998ba104-4bdf-4524-80ce-f05f7a858176`; полный предыдущий снимок и receipt сохранены в `release/previous/`. Cloudflare DNS не менялся. Следующая публикация должна сохранить уже оба выпуска: Pages заменяет весь снимок сайта, а не добавляет папку.

`author.mjs` переводит рабочие издания обратно в draft при пересборке. После правок снова выполнить check-episode, визуальную и браузерную проверку перед ready и публикацией. `prepare-release.mjs` — сборщик именно этого релиза с проверкой старого baseline, не универсальная команда для следующей серии. Исходный утверждённый EP.01 и reference скилла не менялись.
