# TENGU EP.03 — Браузер блокирует. А приложение?

Редакция 2 по обратной связи автора: 7 содержательных экранов + заставка, 20 управляемых фаз вместо 12 экранов / 38 фаз. Сохранены айдентика TENGU, персонажи, локальные шрифты и управление.

Одна история: слабый ключ издателя → возможность подделать сертификат → условия подмены соединения → разные проверки браузера и приложения → доставка исправления → проверка результата.

Формулы, арифметика P-384, процедура CA, отдельная лекция про cross-signing и таблица версий убраны из основного рассказа. Подробная фактура остаётся в приватном SOURCES.md. Первый экран получил отдельную адаптивную сетку без наследования старой сложной композиции.

Из этой папки: `node serve.mjs`. Только localhost, 127.0.0.1:4175.

- RU: http://127.0.0.1:4175/ru/dist/
- EN: http://127.0.0.1:4175/en/dist/
- Приватные reader: `ru/dist/script.html`, `en/dist/script.html`; план с `?view=plan`.

- План: `ru/STORY-PLAN-RU.md`, `en/STORY-PLAN-EN.md`.

P — пауза; R — сброс на паузе; ←/→ — фазы; −/+ — скорость; 0 — нормальная скорость. Вверх/вниз, PageUp/PageDown, пробел/Shift+пробел — экраны. Home/End — заставка/финал. Щелчок запускает MP4 со звуком; клавиши фаз не перематывают MP4.

## Исходники и проверка

`content.mjs` — двуязычная речь и визуальные фазы. `author.mjs` собирает локальные редакции и снова ставит draft: после каждого изменения требуется QA. `episode.css` и `render.js` — композиции и единый таймер.

`verify.cjs` проверяет обе редакции, все фазы, управление, пять размеров, заставку и локальные сценарии. Зависимости Playwright/sharp — через NODE_PATH. `qa/` непублична.

## Публикация и восстановление

- RU: https://tengucluster.com/episodes/emudhra-ca-compromise/
- EN: https://tengucluster.com/en/episodes/emudhra-ca-compromise/

`prepare-revision.mjs` собирает отдельный `release-v2/public/` из полного проверенного снимка сайта и явного списка файлов. Менять разрешено только index.html, app.js, journey.js и episode.css этого выпуска в обеих редакциях. Остальные 131 файл должны быть побайтно прежними. Предыдущие выпуски не изменяются.

`verify-public.mjs <origin> [release-directory]` сверяет хеши и 404 для приватных путей. `prepare-cache-revision.mjs` подготовил завершающий снимок `release-v2-final/`: в двух HTML добавлены версии к адресам JS/CSS, чтобы уже открытые вкладки не смешивали старые скрипты с новыми слайдами. `promote-revision.mjs [release-directory]` обновляет локальный эталон только после опубликованной проверки. При следующем изменении JS/CSS увеличить cache-version в author.mjs.

Предыдущие исходники и сценарии сохранены в `revisions/v1/`, предыдущий полный публичный выпуск — в `release/`. `release-v2/previous/` содержит дополнительный проверенный снимок до изменения.

Никогда не публиковать рабочий dist целиком. Сценарии, планы, skill, заметки, QA и инструменты исключены из загрузки. Текущий статус — в `release-v2-final/deployment-record.json`.
