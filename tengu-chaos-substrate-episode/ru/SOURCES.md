# TENGU EP.05 — Chaos Substrate: evidence ledger

Checked 2026-10-27, revision 9. Firsthand measurements on the owner's machine; no paid services, no network calls except Ollama on localhost and the public GitHub clone. Raw outputs of revision 9 stay in that session's scratchpad (ep05-rev9: old-*.json, new-*.json, measure.sh); the knowledge-base queries are kept privately in ../evidence/rev9/ (K1–K8). None of them is published.

## Environment

Apple M4 (10 cores, 16 GiB), macOS 26.6.2. Ollama 0.24.0 with embeddinggemma (768 dimensions). PostgreSQL 16.15 + pgvector 0.8.2 in Docker. chaos 1.2.0 (code 5a8ecca6c5f973d023abd05cef4f71d174180208, unchanged at ed73a5e0c80651cf6f8c19b8e8c3942186a5f109) and, for the comparison only, chaos 1.1.0 (3c69fa12b485ee72250f9516d3c4bcb097c20f92). chaos-kb 2.0.0 built from ed73a5e0c80651cf6f8c19b8e8c3942186a5f109. Both chaos versions indexed the same fresh public clone at ed73a5e0c80651cf6f8c19b8e8c3942186a5f109, each into its own new database, with the repository's own chaos-substrate.toml settings.
