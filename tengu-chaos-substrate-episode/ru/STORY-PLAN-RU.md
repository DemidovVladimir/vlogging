# TENGU EP.05 — Режиссёрский план

История: агент каждый раз перечитывает код → индекс — это кеш; самое дорогое в нём векторы → каждый сохранённый результат лежит под хешем ровно своего входа; дерево Меркла убрано, потому что сверять без данных тут некому (stateRoot и лёгкий клиент) → после правки пересчитана только разница, замер 1.1 против 1.2 → ответ из индекса → вопрос по нескольким репозиториям → настоящий поиск в базе знаний автора: ищут векторы, отпечаток узнаёт, ключи те же → порядок работы и границы. Объяснение опирается на то, что база знаний автора говорит о нём: Web3 (Solana, EVM) и RAG. Все числа — замеры 27.10.2026; дорожки в 06 — иллюстрация.

- вопрос → точные строки → ещё актуально?

## 02 / Один раз: единицы, связи, фичи — 00:33–01:07

Фазы (R, затем → по мере объяснения):

- Файлы читаются один раз: Rust, TypeScript, JavaScript, Python, Solidity, GraphQL, Markdown.
- Tree-sitter режет каждый файл на единицы, которые человек назвал бы по имени.
- Вызовы и импорты связываются по всему проекту, а не внутри одного файла.
- Тесно связанные единицы образуют фичи — по связям, а не по папкам.
- Векторы — самая дорогая часть: с готовыми векторами та же сборка идёт 22,24 с вместо 264,08.

## 03 / Каждый результат — под хешем своего входа — 01:07–02:09

Фазы (R, затем → по мере объяснения):

- Вектор лежит под хешем своей единицы: её кода и заголовка с путём и строками. Тот же хеш — вектор годится.
- Так же — всё остальное: разбор файла под хешем его байтов, вектор сводки под хешем её текста и модели.
- Правим pack(): меняются хеши единицы и файла — их делают заново. Текст сводки тот же — вектор из базы.
- В 1.1 ключом сводки был хеш дерева над всеми файлами фичи: любая правка в них делала сводку заново.

## 04 / Пересчитывается только изменённое — 02:09–02:43

Фазы (R, затем → по мере объяснения):

- Одна строка-комментарий внутри pack().
- chaos add сравнивает хеш каждого файла с тем, что видел индекс: заново разобран 1 файл из 96.
- Новый вектор — только у 5 единиц: pack() и тех, у кого сдвинулись строки. 1 702 вектора взяты из базы.
- Текст сводок не изменился — ни одна сводка не эмбеддилась заново. Всё — за 1,34 с.

## 05 / Ответ берётся из индекса — 02:43–03:10

Фазы (R, затем → по мере объяснения):

- Вопрос один раз становится вектором и сравнивается со сводками фич.
- Внутри ближайших фич — поиск по смыслу, словам и точным именам, с общим рейтингом.
- Один шаг по вызовам и реализациям добавляет соседей.
- 16 фрагментов с точными строками, 5 980 из 6 000 токенов, 0,14 с. Повторный вопрос — страница из кеша.

## 06 / Один вопрос. Четыре репозитория. — 03:10–03:43

Фазы (R, затем → по мере объяснения):

- Тот же вопрос задаётся каждому репозиторию — каждый отвечает по своему индексу.
- Имя функции из одного репозитория дословно найдено в коде другого — это связь.
- Обычные слова и имена короче шести символов связей не дают.
- Одна страница, четыре дорожки. Бюджет делится, ответ — размером с один.

## 07 / Ищут векторы. Отпечаток узнаёт. — 03:43–04:28

Фазы (R, затем → по мере объяснения):

- Дословный абзац база узнаёт по отпечатку — хешу его слов, без модели: 0,04 с.
- Ключи те же, что в 03: вектор абзаца — под хешем его текста. Корня над всей базой больше нет.

## 08 / Читать меньше. Доверять проверяемому. — 04:28–05:01

Фазы (R, затем → по мере объяснения):

- Индексировать один раз. add — после каждой правки. Вопросы — через feature.
- Ключ — хеш ровно своего входа. Дерево — когда проверяют без данных.
- Хеш доказывает «то же самое», но не «верно».

## Управление и запись

- P: pause/resume; R: reset paused; ← / →: phase back/forward, paused.
- − / +: 0.25×–2×; 0: normal speed.
- Down / PageDown / Space: next; Up / PageUp / Shift+Space: previous. Home / End: intro / closing.
- Wheel / touch: natural scroll. Hidden tabs freeze diagrams. Reduced motion: final phase, manual stepping still works.
- Diagrams hold their final phase rather than looping. Controls do not scrub the MP4.
- Record the deck only. Keep script.html and ?view=plan in a separate LOCAL window/device.
- Замедлиться на 03 (колонки «ключ» и «после правки», затем 1.1 против 1.2): это главная мысль. Хеши и формулы ключей вслух не читать.
