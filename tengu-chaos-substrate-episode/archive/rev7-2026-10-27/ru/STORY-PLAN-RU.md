# TENGU EP.05 — Режиссёрский план

История: агент каждый раз перечитывает код → индекс один раз → хеши, собранные в дерево → после правки только разница → ответ из индекса → вопрос сразу по нескольким репозиториям → «это уже известно?» в chaos-kb → порядок работы и границы. Все числа — замеры 27.10.2026; схема с дорожками — иллюстрация с выдуманными именами.

## 00 / Интро — 00:00–00:03

Нажать запуск, дать закончиться MP4 со звуком.

## 01 / Агент снова читает тот же код — 00:03–00:31

Фазы (R, затем → по мере объяснения):

- поиск → открыть файлы → ответ → забыто
- вопрос → точные строки → ещё актуально?

## 02 / Один раз: единицы, связи, фичи — 00:31–01:10

Фазы (R, затем → по мере объяснения):

- Файлы читаются один раз: Rust, TypeScript, JavaScript, Python, Solidity, GraphQL, Markdown.
- Tree-sitter режет каждый файл на единицы, которые человек назвал бы по имени.
- Вызовы и импорты связываются по всему проекту, а не внутри одного файла.
- Тесно связанные единицы образуют фичи — по связям, а не по папкам.
- Каждая единица становится вектором: числами, которые передают её смысл.

## 03 / Отпечаток из отпечатков — 01:10–01:50

Фазы (R, затем → по мере объяснения):

- У каждой единицы — хеш её текста. Тот же текст — тот же хеш.
- Хеш файла — из хешей единиц; хеш фичи — из её файлов; корень — из всех файлов.
- Меняем одну функцию: меняются только хеши на её пути — файл, фича, корень.
- Равные хеши — равное содержимое. Сохранённый результат можно взять, не перечитывая.

## 04 / Пересчитывается только изменённое — 01:50–02:27

Фазы (R, затем → по мере объяснения):

- Одна строка изменилась внутри одной функции.
- chaos add сравнивает хеш каждого файла с сохранённым: заново читается один файл.
- Новые векторы — только для единиц, чей текст изменился: 5 из 1 690.
- Новая сводка — только у фич, чей хеш сдвинулся: 3 из 33. Готово за 1,73 с.

## 05 / Ответ берётся из индекса — 02:27–03:03

Фазы (R, затем → по мере объяснения):

- Вопрос один раз становится вектором и сравнивается со сводками фич.
- Внутри ближайших фич — поиск по смыслу, словам и точным именам, с общим рейтингом.
- Один шаг по вызовам и реализациям добавляет соседей.
- 11 фрагментов с точными строками, 6 000 токенов, 0,20 с. Повторный вопрос — страница из кеша.

## 06 / Один вопрос. Четыре репозитория. — 03:03–03:42

Фазы (R, затем → по мере объяснения):

- Тот же вопрос задаётся каждому репозиторию — каждый отвечает по своему индексу.
- Имя функции из одного репозитория дословно найдено в коде другого — это связь.
- Обычные слова и имена короче шести символов связей не дают.
- Одна страница, четыре дорожки. Бюджет делится, ответ — размером с один.

## 07 / Точные слова — это поиск, а не модель — 03:42–04:20

Фазы (R, затем → по мере объяснения):

- Точные слова абзаца: только хеш и поиск среди листьев дерева. Модель не нужна.
- Другие слова: сравнивается смысл ближайших абзацев с порогом 0,38.
- Ниже порога — знания нет. Такой факт агенту стоит запомнить.
- Добавили факт — корень другой. Забыли — корень ровно прежний.

## 08 / Читать меньше. Доверять проверяемому. — 04:20–04:53

Фазы (R, затем → по мере объяснения):

- Индексировать один раз. add — после каждой правки.
- Спрашивать через feature; --all-repos — если фича в нескольких репозиториях.
- Хеш доказывает «то же самое», но не «верно».

## Управление и запись

- P: pause/resume; R: reset paused; ← / →: phase back/forward, paused.
- − / +: 0.25×–2×; 0: normal speed.
- Down / PageDown / Space: next; Up / PageUp / Shift+Space: previous. Home / End: intro / closing.
- Wheel / touch: natural scroll. Hidden tabs freeze diagrams. Reduced motion: final phase, manual stepping still works.
- Diagrams hold their final phase rather than looping. Controls do not scrub the MP4.
- Record the deck only. Keep script.html and ?view=plan in a separate LOCAL window/device.
- Замедлиться на дереве Меркла (03) и на корне в 07: это главная мысль. Хеши в 07 не читать вслух.
