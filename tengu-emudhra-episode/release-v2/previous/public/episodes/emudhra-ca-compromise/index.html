Большая кривая. Крошечный секрет.

Q = d × G: открытый ключ Q вычисляется из секретного числа d.

dd — закрытый ключ×GG — заданная точка кривой=QQ — открытый ключ
1F68B1FA438CD51E67B0F9428BD41D66AFF8418AD31C65AEF74089D21B64ADF63F88D11A63ACF53E87D01962ABF43D86
48 байт: 47 нулевых + один ненулевойВсего 255 ненулевых кандидатов → Q ✓

При нормальной генерации d выбирается непредсказуемо из огромного диапазона.

× — умножение точки кривой на число. Схема, не программа восстановления ключей. NIST / ECDSA ↗CERT-In / advisory ↗Ali Mosajjal / analysis ↗

06 / TENGU · FIELD STUDY 03

Подмена сервера, не машина времени

Опасность возникает, когда клиент принимает поддельную идентичность сервера.

  1. 01Клиент → Настоящий сервис
  2. 02Клиент → Подмена на пути → Настоящий сервис
  3. 03Две отдельные TLS-сессии
  4. 04Ключ CA ≠ ключи этих сессий

Обычная сессия: клиент проверяет сервер и согласует ключи шифрования.

Модель угроз, не демонстрация атаки. Forward secrecy — защита прошлых сессий при последующей утечке долгосрочного ключа. RFC 8446 / TLS 1.3 ↗Cloudflare / response ↗

Подпись, отзыв и CT — разные проверки

Одна корректная цепочка не гарантирует, что сертификат будет принят.

Цепочка + имя✓ Подпись корректна
Отзыв / блокировка× Ключ больше не доверенный
Certificate Transparency× Нет подходящих SCT

Клиент с CT / блокировкойОТКЛОНИТЬ

Клиент без этих проверокМОЖЕТ ПРИНЯТЬ

Подпись отвечает: соответствует ли сертификат ключу издателя?

Google: до блокировки не было TLS-сертификатов этих CA в CT. CRLSet — не полный список всех отзывов. RFC 6962 / CT ↗Chromium / CRLSets ↗Google / response ↗OpenSSL / verification ↗

08 / TENGU · FIELD STUDY 03

Одна macOS. Не одна система доверия.

Проверяет сертификат конкретная TLS-библиотека с конкретной конфигурацией.

Браузер / native API→Системная политика и блокировки→Отклоняет
Встроенный CLI-путь→/etc/ssl/cert.pem→Может доверять старому CA
curl из другой сборки→Другой backend / CA bundle→Проверить отдельно
command -v curlcurl -VПуть и backend; не тест безопасности сами по себе.

Обновление системной политики защищает клиентов, которые её используют.

Наблюдение для встроенного CLI-пути из incident guide на 22.10.2026. Не утверждение обо всех версиях macOS/curl. curl / trust stores ↗Dennis Jackson / checks ↗
