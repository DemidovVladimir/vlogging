## Ход истории

Ошибка идентификации сервера → Cloudflare как TLS-клиент → доставка патча до работающего приложения → клиентские программы → origin и mTLS → граница HTTPS interception → зависимости под SDK → быстрое обновление доверия.

Без лекции о P-384, cross-signing и Go. Node.js и Requests — поясняющие примеры, не утверждения о внутренних системах Cloudflare. Изменения на схемах иллюстративные: страница не проверяет сертификаты, не исполняет команды и не меняет настройки компьютера.
