# Aave Documentation

> Technical documentation for Aave Protocol (v3 & v4), GHO stablecoin, and governance. For protocol integrators and frontend engineers.

Aave is a decentralized non-custodial liquidity protocol. This documentation covers AaveKit (React/TypeScript/GraphQL SDK), smart contract references, and integration guides.

## When to use these docs

Use this documentation to integrate Aave or act on it programmatically: reading market data and rates, building supply, borrow, repay, withdraw, and swap transactions, GHO and Savings GHO, staking (Umbrella), governance, and liquidations. Start with Aave 101 for concepts, the AaveKit getting-started guides for the SDKs, or the smart contract references for direct onchain integration. Every page is also available as markdown: append .md to any page URL, or send Accept: text/markdown.

## Programmatic access

- [Aave GraphQL API, v4](https://api.v4.aave.com/graphql): public endpoint for v4 market data, user positions, and transaction building. No API key required.
- [Aave GraphQL API, v3](https://api.v3.aave.com/graphql): public endpoint for v3 markets across supported chains.
- [Aave MCP server](https://mcp.aave.com): remote Model Context Protocol server for AI agents. Read markets and positions, simulate actions, and prepare unsigned Aave transactions for the user's wallet to sign.
- [OpenAPI description](https://aave.com/openapi.json): the GraphQL-over-HTTP transport of the v4 API, machine-readable. The APIs are permissionless: no keys and no sign-in of any kind.
