# Kamino API

Access comprehensive data for Kamino Earn vaults, lending markets, user positions, and transaction endpoints to seamlessly integrate yield strategies and borrowing functionality into your applications.

## Base URL

All Kamino API requests use the following base URL:

```bash theme={null}
https://api.kamino.finance
```

## Distributor codes

Third parties that direct deposits into Kamino can tag their deposits and withdrawals with a distributor code and read back the attributed flow. See [Distributor codes](https://kamino.com/docs/build/api-reference/distributors.md).
