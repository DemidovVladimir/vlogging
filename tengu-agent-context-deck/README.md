## Локальный запуск

Запустить из этой папки: python3 -m http.server 4173 --bind 127.0.0.1 --directory dist

Открыть http://127.0.0.1:4173/ и отдельно http://127.0.0.1:4173/script.html. При открытии HTML двойным кликом загрузку сценария может блокировать браузер.

## Управление

- Вниз / Page Down / Space: следующий слайд.
- Вверх / Page Up / Shift + Space: предыдущий.
- Home / End: начало / финал.
- P: пауза или продолжение анимации.
- Влево / вправо: предыдущая или следующая фаза с паузой.
- R: первая фаза на паузе.
- Минус / плюс: скорость 0,25×–2×. 0: обычная скорость.
- Колесо и touch: естественная прокрутка.

P/R работают по физическим клавишам и с русской раскладкой. Пауза и скорость сохраняются при смене слайда. Reduced motion отключает автоматический ход, но оставляет ручные фазы. Управление относится к схемам, не к MP4. Заставка запускается кликом со звуком.
