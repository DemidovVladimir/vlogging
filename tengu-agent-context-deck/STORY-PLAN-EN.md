## Story

A request misses its intended format → inspect the assembled input → see context change the answer → find the conflicting instruction → distinguish procedures from tools → follow new data into the next call → recognize an untrusted command → understand what caching does not solve → recheck old skills after model changes.

Each scene adds a new point. The first scene poses the problem; scene 05 resolves it. Scene 10 adds a different reason to revisit configuration, not another explanation of instruction priority.
